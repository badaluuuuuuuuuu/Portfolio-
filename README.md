# BADAL_ — Portfolio

A premium animated personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure/content
- `style.css` — design, responsive layout and animations
- `script.js` — particles, cursor glow, scroll reveal and mobile menu

## Run locally
Open `index.html` in Chrome.

## Put it live with GitHub Pages
1. Create a GitHub repository (for example `portfolio`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. In GitHub: Settings → Pages.
4. Select the `main` branch and `/root` folder.
5. Save. GitHub will provide your live website URL.
